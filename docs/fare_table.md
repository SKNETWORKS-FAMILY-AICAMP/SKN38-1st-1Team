# 짐니 실제 요금 기준표

**예상 운임 계산식**

**계산식 정리**

```
① 차량 결정     적재율 = Σ (등급별 짐 개수 ÷ 차량 최대 수량) ≤ 1  → 가장 작은 차량
② 기본 운임     운임표[거리 구간(운송 거리)][차량]
③ 운임         기본 운임 + 인력 + 출발지 계단 + 도착지 계단
④ 서비스 이용료  운임 × 5%   (100원 단위 반올림)
⑤ 고객 결제액    운임 + 서비스 이용료
⑥ 기사 수수료    운임 × 18%  (100원 단위 반올림)
⑦ 기사 정산액    운임 − 기사 수수료
⑧ 플랫폼 수익    서비스 이용료 + 기사 수수료  (운임의 약 23%)
```

**차량 고르는 방법**

- **한 종류만 있을 때**: 작은 차부터 보면서 수량이 최대치 이하인 첫 차량
- **여러 종류가 섞였을 때**: 차량마다 "개수 ÷ 최대 수량"을 등급별로 더해서 1 이하인 첫 차량
- **XL·XXL이 하나라도 있으면** 무조건 1톤 (적재 확인 필요 표시)
